# Product Management App
This project was created as a **code challenge** for a working student position at **Check24**. The application demonstrates 
a implementation of the **MVVM architecture** in Android, using **Jetpack Compose** for the UI.

## Features
- **Product Listing**: Displays a list of products fetched from a remote API.
- **Product Details**: Allows users to view detailed information about a selected product.
- **Marking Products**: Users can mark products as "favorites" or "forget them" to manage their preferences.
- **Filter Products**: Filter products by availability, marked status, or display all.
- **Error Handling**: Displays appropriate error messages when network or other issues occur.
- **Pull-to-Refresh**: Allows users to refresh the product list manually.
- **Footer with Navigation**: A footer navigates to a WebView for additional legal notes.

## Tech Stack
- **Programming Language**: Kotlin
- **Architecture**: MVVM (Model-View-ViewModel)
- **UI Framework**: Jetpack Compose
- **Network Library**: Retrofit
- **Local Database**: Room
